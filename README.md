# Calendar

A simple, private calendar for **events** and **daily notes**. Installable as a PWA on iPhone, Android and desktop, and works fully offline.

## Your data
- Stored only on your device (IndexedDB). Nothing is uploaded.
- **Back up** → saves a `.json` file (share sheet on phones: Files, iCloud Drive, Google Drive…).
- **Restore** → loads a backup file (with undo).
- Desktop Chrome / Edge: optionally **link a file** that updates automatically after every change.

## Install on your phone
- **iPhone (Safari):** Share → *Add to Home Screen*
- **Android (Chrome):** menu → *Install app*

## Keyboard (desktop)
`←/→/↑/↓` move day · `PgUp/PgDn` month · `T` today · `N` / `Enter` new event

## Hosting
Static files only — any HTTPS host works (GitHub Pages, Netlify, Cloudflare Pages).
Bump `VERSION` in `sw.js` when you publish changes.
